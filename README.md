# WinCleaning

Скрипт PowerShell для очистки диска Windows. Удаляет мусор Docker и сжимает его виртуальный диск, чистит кэши браузеров и драйверов, временные файлы и старые обновления Windows. В конце показывает таблицу: сколько места освободил каждый шаг.

## Быстрый запуск

Откройте PowerShell и выполните:

```powershell
irm https://raw.githubusercontent.com/jrfrigat/WinCleaning/main/run.ps1 | iex
```

Скрипт сам запросит права администратора и покажет меню выбора шагов.

Запуск с параметрами (например, только шаги 3, 4 и 5):

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/jrfrigat/WinCleaning/main/run.ps1))) -Steps 3,4,5
```

Или скачайте репозиторий и дважды щёлкните по `CleanAll.bat`.

## Шаги

При запуске скрипт показывает меню: номера через запятую включают и выключают шаги, `a` выбирает все, `n` снимает все, Enter запускает, `0` закрывает скрипт.

| № | Шаг | Что удаляется |
|---|---|---|
| 1 | Docker | Тома, образы, кэш сборки и сети, не привязанные ни к одному контейнеру |
| 2 | Сжатие дисков Docker | Останавливает Docker Desktop и WSL, сжимает VHDX-файлы Docker, запускает Docker обратно |
| 3 | Кэши браузеров | Кэш Chrome, Chrome Canary, Edge, Яндекс Браузера, Brave, Opera, Firefox |
| 4 | Кэши драйверов | Кэш шейдеров NVIDIA/AMD/Intel, кэш DirectX, старые скачанные установщики драйверов NVIDIA |
| 5 | Временные файлы | Temp пользователя и Windows, дампы падений, отчёты об ошибках, кэши NuGet и npm, WorkspaceStorage VS Code, корзина |
| 6 | Обновления Windows | Скачанные файлы обновлений, кэш оптимизации доставки, заменённые компоненты (`DISM /StartComponentCleanup`) |

Пример итога:

```
Шаг                         Свободно до  Свободно после  Освобождено
Docker                      22,8 ГБ      22,8 ГБ         0,00 ГБ
Сжатие дисков Docker        22,8 ГБ      180,5 ГБ        157,70 ГБ
Кэши браузеров              180,5 ГБ     181,6 ГБ        1,10 ГБ
```

Место, освобождённое внутри Docker (шаг 1), появляется на диске только после сжатия (шаг 2).

## Что скрипт не трогает

- **Пароли, cookies, историю, закладки и расширения браузеров.** Удаляются только папки кэша. Запущенный браузер скрипт закроет только с вашего разрешения.
- **Остановленные контейнеры Docker и их тома.** Удаляются только тома, не привязанные ни к одному контейнеру. Перед удалением скрипт покажет их список и спросит подтверждение.
- **Файлы, занятые программами.** Они пропускаются без ошибок.

Удалённое восстановить нельзя. Перед первым запуском проверьте список томов Docker, который покажет скрипт.

## Параметры

| Параметр | Описание |
|---|---|
| `-Steps 1,2,5` | Выполнить указанные шаги без меню |
| `-Yes` | Не задавать вопросов: выполнить все шаги (или шаги из `-Steps`), удалить тома Docker и закрыть браузеры без подтверждения |
| `-NoPause` | Не ждать нажатия клавиши в конце |

## Требования

- Windows 10 или 11, встроенный Windows PowerShell 5.1.
- Учётная запись с правами администратора. Если ввести пароль другого администратора, системные шаги сработают, а пользовательские папки (Temp, кэши браузеров) скрипт возьмёт у того, кто его запустил.
- Для шагов 1–2: Docker Desktop. Сжатие работает через `Optimize-VHD`, если включён Hyper-V, иначе через `diskpart`.
